
# Abstract Search, Download, Analyze, Summarize

This sub-project is a simplified version of the full-paper version.
It does not attempt a full literature review.
Rather, it searches for papers, downloads their abstracts, and provides a summary.
See configuration.py for various user-level settings, including the user prompt.
The result is a summary of what the abstracts contain and a review of each abstract.
See the Database directory for that report and a webpage pointing to the full papers.
For each new run, rename database.db to previous-topic.db and start without a database.db.
Also, rename search_results.html to previous-topic.html.
